# Pingo: Uma aventura na rede

**Pingo: Uma aventura na rede** é um jogo em desenvolvimento, criado como projeto da faculdade.  
O objetivo do jogo é proporcionar diversão enquanto aplicamos conceitos de Programação Orientada a Objetos e Banco de Dados.

---

## Status do Projeto

- Projeto em fase inicial.  
- Código ainda não implementado.

---

## Estrutura do Repositório

Este repositório segue o modelo de versionamento Git Flow. As principais branches são:

- `main`: contém o código da versão estável e pronta para produção.  
- `develop`: branch principal de desenvolvimento com as últimas funcionalidades em progresso.  
- `feature/*`: utilizadas para desenvolver novas funcionalidades.  
- `release/*`: usadas para preparar uma nova versão antes de enviá-la para a `main`.  
- `hotfix/*`: utilizadas para corrigir problemas críticos diretamente na `main`.
- `<nome>/<sprint>`: branches individuais de Juniores criadas para cada sprint.


---

## Como contribuir

- Crie uma branch `feature/nome-da-funcionalidade` a partir da `develop`.  
- Implemente a funcionalidade seguindo as boas práticas do projeto.  
- Faça commits claros e frequentes.  
- Ao finalizar, abra um Pull Request para `develop`.  
- Em caso de correções urgentes, utilize uma branch `hotfix/nome-do-fix` a partir da `main`.

---

## Convenções

- Use nomes descritivos para as branches: `feature/menu-principal`, `hotfix/bug-login`, etc.  
- Escreva mensagens de commit claras e objetivas.  
- Realize revisões de código antes de aceitar Pull Requests.
