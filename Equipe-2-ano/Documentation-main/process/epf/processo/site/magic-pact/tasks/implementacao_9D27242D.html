Task: Implementação
Implementar o código da tarefa.
Purpose
Desenvolver o código da tarefa atribuída dentro do prazo definido e aderindo aos padrões de qualidade estabelecidos pelo processo.
Relationships
RolesPrimary Performer:
  • Desenvolvedor Júnior
  • Desenvolvedor Pleno
  • Desenvolvedor Sênior
  • Designer de BD
  • Projetista de BD
Additional Performers:
  • Projetista Sênior Front-end
Main Description
A tarefa de Desenvolvimento consiste em cada membro da equipe responsável por uma tarefa específica implementar o código necessário para sua conclusão. Cada membro deve cumprir os prazos especificados enquanto desenvolve a tarefa de forma satisfatória, aderindo aos padrões de desenvolvimento estabelecidos e aos requisitos especificados. Durante o processo, é incentivado que sejam realizadas seções de programação par a par, nas quais dois membros da equipe trabalham juntos em determinadas etapas do desenvolvimento, promovendo a colaboração, revisão de código, troca de conhecimentos e identificação de melhores práticas, o mais indicado é que as duplas consistam em pessoas com níveis de habilidade diferentes, para que um possa ensinar o outro. Além disso, é fundamental manter uma comunicação efetiva com os demais membros da equipe, buscando suporte e esclarecimento de dúvidas. O processo também envolve etapas como atualizar o repositório local para obter a versão mais recente do código-fonte, realizar commit local das alterações, criar um pull request para revisão e integração do código ao repositório principal e comunicar o término da tarefa para a equipe.
Steps
Atualização de Arquivos Locais
Atualizar o repositório local para obter a versão mais recente do código-fonte.
Desenvolvimento da Tarefa
Desenvolver a tarefa atribuída, aderindo aos padrões de desenvolvimento e cumprindo os requisitos especificados.
Submissão do Código
Realizar commit local das alterações. Criar um pull request para revisão e integração do código ao repositório principal.
Solicitação de Revisão
 Solicitar a revisão dos membros da equipe ao comunicar término da tarefa.
Key Considerations
Ao final dessa etapa, espera-se ter o código produzido, pronto para ser integrado e testado em conjunto com as demais partes do sistema.
