Task: Desenvolvimento de Testes
Criar testes unitários e submeter códigos produzidos a estes testes.
Purpose

Ter testes criados para poder validar a qualidade dos códigos produzidos na Tarefa de desenvolvimento.

Relationships
RolesPrimary Performer:
  • Analista de Qualidade Júnior
Additional Performers:
Main Description
Pensar nos cenários possíveis que podem gerar erros e criar testes unitários baseados nesses cenários é uma prática fundamental no desenvolvimento de software. Os testes unitários são responsáveis por verificar se as unidades individuais de código, como funções, métodos ou classes, estão funcionando corretamente.
Steps
Identificação de Cenários de Erro
Desenvolvimento dos Testes Unitários
Criação e desenvolvimento dos testes unitários aos quais o código será submetido.
Apuração dos Testes
Criar Pull Request do Teste unitário. Aprovar ou reprovar Pull Request .
