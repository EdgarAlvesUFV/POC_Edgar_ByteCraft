Artifact: Plantao tecnico
Ter desenvolvedores seniores de plantão oferece suporte imediato para a resolução de problemas críticos que possam surgir durante o desenvolvimento. Isso reduz o tempo de inatividade e aumenta a qualidade do código produzido, além de proporcionar mentoria para desenvolvedores menos experientes.
Purpose
O objetivo principal desta tarefa é justamente auxiliar os desenvolvedores juniors como em uma monitoria, mas de forma reduzida e flexível para o desenvolvedor senior.
Description
Main Description

É um tipo de reunião que ocorre durante o período, sendo parecido como uma monitoria, envolvendo todo e qualquer aluno que for implementar alguma parte do software.

Ocorre durante a Fase de Produção na Implementação.
