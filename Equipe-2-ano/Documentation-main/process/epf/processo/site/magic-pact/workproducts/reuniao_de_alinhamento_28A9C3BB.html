Artifact: Reunião de Alinhamento
Reunião que ocorre no início do desenvolvimento para alinhar os interesses e objetivos da sprint.
Purpose

Objetivo é explicar o sprint backlog diretamente aos envolvidos das equipes, de forma que o entendimento fique claro do que deve ser feito.

Description
Main Description

A Reunião de Alinhamento ocorre rapidamente no início de toda sprint de desenvolvimento, dessa forma os alunos das equipes podem sanar dúvidas com relação ao sprint backlog e receber um esclarecimento e direcionamento da execução de suas tarefas.
