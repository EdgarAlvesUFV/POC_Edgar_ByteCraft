Main Description

As equipes de Arquitetura de Software são compostas por dois alunos e cada um deve assumir um dos seguintes papéis:

Aluno 1 - Arquiteto de Software

Aluno 2 - Designer de Software

Ambos os alunos exercerão o papel de Desenvolvedor Pleno em cada Desenvolvimento da Fase de Produção.

No caso de um só aluno compor a equipe de Arquitetura de Software de um grupo, ele ficará responsável por ambos os papéis.
