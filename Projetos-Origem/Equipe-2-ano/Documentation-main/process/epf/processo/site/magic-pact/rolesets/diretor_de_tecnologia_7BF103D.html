Role Set: Diretor de Tecnologia
Papéis do responsável pelas decisões de tecnologia do projeto.
Relationships
Roles
  • Arquiteto de Software
  • Designer de Software
  • Desenvolvedor Pleno
Main Description
Responsável pelas decisões específicas de implementação, configuração de ambientes, preparação de plataformas e auxílio dos demais membros da equipe. O Diretor de Tecnologia detém as tarefas de Arquiteto de Software, Designer de Software e Programador Sênior Auxiliar.
