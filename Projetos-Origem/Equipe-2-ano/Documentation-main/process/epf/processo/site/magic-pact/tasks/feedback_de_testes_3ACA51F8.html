Task: Feedback de Testes
Relatar informações encontradas ao realizar os testes.
Purpose
Identificar erros para poder corrigi-los, verificar qualidade do código produzido.
Relationships
RolesPrimary Performer:
  • Analista de Qualidade Júnior
Additional Performers:
Main Description
Relatar as informações encontradas ao realizar os testes é uma etapa crucial no processo de testes unitários. O propósito principal é identificar erros no código para que possam ser corrigidos e garantir a qualidade do código produzido.
Steps
Avaliação dos Resultados de Teste
Geração de Resultado
Aprovação do incremento ou criação de Issues no GitHub. Caso uma Issue seja gerada, listar quais erros foram encontrados, ordená-los por prioridade e descrever os cenários.
Key Considerations
Os resultados dos testes são apurados, gerando ou não Issues.
