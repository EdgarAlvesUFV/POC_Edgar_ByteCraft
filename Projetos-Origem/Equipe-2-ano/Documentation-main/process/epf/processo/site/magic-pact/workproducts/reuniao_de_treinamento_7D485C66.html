Artifact: Reunião de Treinamento
Reunião que ocorre no início do projeto integrador.
Purpose

Objetivo é reunir os membros necessários das equipes e realizar sessões de treinamento e familizarização.

Relationships

Description
Main Description

É um tipo de reunião que ocorre no início do período, envolvendo todo e qualquer aluno que precise passar pelo treinamento e familiarização com alguma ferramenta que será utilizada durante o projeto.

Ocorre durante Fase de Iniciação, no Gerenciamento do Projeto, seja no Treinamento do Processo ou no Treinamento de Ferramentas.

Se necessário, qualquer outro acontecimento desse evento deve ser documentado com a explicitação dos motivos para isso.
