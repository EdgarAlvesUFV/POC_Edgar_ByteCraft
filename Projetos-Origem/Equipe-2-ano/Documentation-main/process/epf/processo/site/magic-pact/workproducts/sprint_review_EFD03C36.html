Artifact: Sprint Review
Reunião que ocorre ao final da sprint.
Purpose

Objetivo é assimilar todas as informações obtidas na sprint, preparando o próximo ciclo de desenvolvimento.

Relationships
RolesResponsible:
  • Líder do Projeto
Modified By:
Description
Main Description

A Sprint Review reúne os membros do projeto para coletar o feedback necessário para a próxima sprint, reunindo tudo que foi gerado pela sprint atual e enviando as métricas dos alunos para os professores de cada matéria.

Nessa reunião, o resultado da sprint de Modelagem é coletado, junto ao feedback, para que o Líder do Projeto possa preparar a próxima reunião de Sprint Planning.
