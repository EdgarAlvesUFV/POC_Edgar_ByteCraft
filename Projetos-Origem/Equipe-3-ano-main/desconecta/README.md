# Pasta Desconecta

Este diretório é dedicado para o desenvolvimento e versionamento do código principal do software **(Des)conecta**. Aqui está organizado o sistema completo do jogo, dividido em suas principais camadas de desenvolvimento.

## 📁 Estrutura de Desenvolvimento

O desenvolvimento do jogo está organizado em três diretórios principais:

### 🖥️ **[backend](/desconecta/backend/)**
Diretório dedicado para o desenvolvimento do código backend do projeto

### 🗄️ **[database](/desconecta/database/)**
Diretório dedicado para o desenvolvimento do banco de dados do projeto

### 🎨 **[frontend](/desconecta/frontend/)**
Diretório dedicado para o desenvolvimento do código frontend do projeto

## 🐳 Docker Compose

Arquivo de integração dos contêineres usados para o projeto.
